# Ejercicio-16---Modelo-Entidad-Relaci-n-de-un-Sistema-de-Gesti-n-Inmobiliaria
Este ejercicio consiste en diseñar un modelo Entidad-Relación (DER) para un sistema de gestión inmobiliaria[cite: 10]. El modelo permite administrar propietarios, propiedades, contratos de alquiler, inquilinos, empleados y el registro de pagos[cite: 10].
